# Zolana Flutter SDK

Typed Dart bindings for Zolana's Rust transaction primitives and local
Mopro/gnark Groth16 proving. The package is generated by Mopro and Flutter Rust
Bridge and supports Android and iOS.

```dart
import 'dart:typed_data';

import 'package:zolana_mobile/zolana_mobile.dart';

await RustLib.init();
final recipient = await shieldedAddress(seed: List.filled(32, 8));
final draft = await prepareTransfer(
  request: TransferDraftRequest(
    senderSeed: Uint8List.fromList(List.filled(32, 7)),
    recipient: recipient,
    inputLamports: BigInt.from(1000000),
    transferLamports: BigInt.from(250000),
  ),
);
```

`proveAssignment` accepts the path to a gnark `.pk` and a flattened decimal
witness JSON. Keep the matching `.r1cs` and `.vk` beside the `.pk` with the same
basename. Proof generation and verification run locally through Mopro's native
gnark adapter; see `../../README.md` for setup and demo instructions.
